# Hotel Reservation Analytics Dashboard

## Project Overview

This project uses Power BI to analyze hotel reservation data and understand booking patterns, cancellation behavior, and guest preferences.

## Project Objectives

* Analyze monthly reservation trends.
* Monitor booking cancellation rates.
* Understand the relationship between lead time and cancellations.
* Compare room type performance.
* Identify insights to support hotel business decisions.

## Tools Used

* Power BI
* DAX
* Data Cleaning
* Data Visualization

## Key Insights

* October recorded the highest number of bookings.
* January and February had relatively low booking activity.
* Approximately 33% of reservations were cancelled.
* Reservations with longer lead times showed notable cancellation patterns.
* Room Type 1 had the highest reservation count.
